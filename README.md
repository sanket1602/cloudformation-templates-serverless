# Clodformation templates for various AWS Resources

This repo includes Cloudformation templates for various AWS Services like Lambda Functions, Rest API Gateway resource, S3 Buckets, ECS Task Definitions, CloudWatch Rules for Task Definitions.
I have worked on this serverless stuff over 3 years and I created this templates as per my client's requirements, you may modify it according your requirement.

You can find more details about Cloudformation templates here - https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/template-snippets.html
